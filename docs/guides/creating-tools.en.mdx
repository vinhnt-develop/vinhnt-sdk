# Creating Tools

Tools are the building blocks that give your agent the ability to interact with the world. This guide walks you through creating custom tools using the `defineTool` function from `@vinhnt-sdk/tools`.

## Tool Anatomy

Every tool is created using `defineTool` and must include:

```typescript
import { defineTool } from "@vinhnt-sdk/tools";

const myTool = defineTool({
  name: "my_tool",
  description: "What this tool does",
  risk: "read",
  input: z.object({
    param: z.string().describe("Description of the parameter"),
  }),
  execute: async (input, context) => {
    // Tool logic here
    return { result: "success" };
  },
});
```

### Required Fields

| Field | Type | Description |
|-------|------|-------------|
| `name` | `string` | Unique identifier for the tool |
| `description` | `string` | Human-readable description of what the tool does |
| `risk` | `RiskLevel` | The risk level of the tool's operation |
| `input` | `z.ZodType` | Zod schema defining the input parameters |
| `execute` | `function` | Async function that performs the tool's action |

## Risk Levels

The `risk` field tells the agent how dangerous a tool is. Always choose the most restrictive level that applies.

| Risk Level | Description | Examples |
|------------|-------------|----------|
| `read` | Only reads data, no side effects | Search, query, list |
| `write` | Creates or modifies data | Create file, update record |
| `destructive` | Permanently removes or alters data | Delete file, drop table |
| `external` | Calls external services or APIs | HTTP requests, webhooks |

## ToolContext Object

The second parameter in `execute` is a `ToolContext` object:

```typescript
execute: async (input, context) => {
  // Ask the user for confirmation
  const confirmed = await context.ask("Proceed with this action?");

  // Log information
  context.logger.info("Starting operation...");

  // Access metadata about the current session
  const sessionId = context.metadata.sessionId;

  return { confirmed };
};
```

### Context Properties

- `ask(message: string): Promise<string>` - Prompt the user for input
- `logger` - Logging interface with `info`, `warn`, `error` methods
- `metadata` - Session and request metadata

## Basic Tool Example

A simple calculator tool:

```typescript
import { defineTool } from "@vinhnt-sdk/tools";
import { z } from "zod";

const calculator = defineTool({
  name: "calculator",
  description: "Perform basic arithmetic calculations",
  risk: "read",
  input: z.object({
    operation: z.enum(["add", "subtract", "multiply", "divide"]),
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
  execute: async (input, context) => {
    context.logger.info(`Calculating ${input.a} ${input.operation} ${input.b}`);

    let result: number;
    switch (input.operation) {
      case "add": result = input.a + input.b; break;
      case "subtract": result = input.a - input.b; break;
      case "multiply": result = input.a * input.b; break;
      case "divide":
        if (input.b === 0) throw new Error("Division by zero");
        result = input.a / input.b;
        break;
    }

    return { result, expression: `${input.a} ${input.operation} ${input.b} = ${result}` };
  },
});
```

## Advanced: External API Tool

A weather tool that calls an external API:

```typescript
import { defineTool } from "@vinhnt-sdk/tools";
import { z } from "zod";

const weather = defineTool({
  name: "get_weather",
  description: "Get current weather for a location",
  risk: "external",
  input: z.object({
    city: z.string().describe("City name"),
    units: z.enum(["celsius", "fahrenheit"]).default("celsius"),
  }),
  execute: async (input, context) => {
    context.logger.info(`Fetching weather for ${input.city}`);

    const apiKey = process.env.WEATHER_API_KEY;
    const response = await fetch(
      `https://api.weather.example/v1/current?city=${encodeURIComponent(input.city)}&units=${input.units}`,
      { headers: { Authorization: `Bearer ${apiKey}` } }
    );

    if (!response.ok) {
      throw new Error(`Weather API error: ${response.statusText}`);
    }

    const data = await response.json();
    return {
      city: input.city,
      temperature: data.temp,
      conditions: data.conditions,
      humidity: data.humidity,
    };
  },
});
```

## Input Validation with Zod

Zod schemas provide runtime validation and type inference:

```typescript
import { z } from "zod";

const schema = z.object({
  // String with constraints
  email: z.string().email().describe("User email address"),

  // Number with range
  age: z.number().int().min(0).max(150).describe("User age"),

  // Optional fields
  nickname: z.string().optional().describe("Optional nickname"),

  // Arrays
  tags: z.array(z.string()).describe("List of tags"),

  // Enums
  status: z.enum(["active", "inactive", "pending"]),

  // Nested objects
  address: z.object({
    street: z.string(),
    city: z.string(),
    zip: z.string().regex(/^\d{5}$/),
  }),

  // Default values
  format: z.enum(["json", "text"]).default("json"),
});

// Type is automatically inferred
type SchemaInput = z.infer<typeof schema>;
```

## Dynamic Registration

Register tools dynamically at runtime:

```typescript
import { ToolRegistry } from "@vinhnt-sdk/tools";

const registry = new ToolRegistry();

// Register tools individually
registry.register(calculator);
registry.register(weather);

// Register multiple tools at once
registry.registerBatch([calculator, weather]);

// Retrieve a tool
const tool = registry.get("calculator");

// List all registered tools
const allTools = registry.list();

// Unregister a tool
registry.unregister("calculator");
```

## Testing Tools with FakeToolContext

Use `FakeToolContext` for unit testing:

```typescript
import { FakeToolContext } from "@vinhnt-sdk/tools";

describe("calculator tool", () => {
  it("should add two numbers", async () => {
    const context = new FakeToolContext();

    const result = await calculator.execute(
      { operation: "add", a: 2, b: 3 },
      context
    );

    expect(result.result).toBe(5);
    expect(context.logs).toContain("Calculating 2 add 3");
  });

  it("should throw on division by zero", async () => {
    const context = new FakeToolContext();

    await expect(
      calculator.execute({ operation: "divide", a: 1, b: 0 }, context)
    ).rejects.toThrow("Division by zero");
  });
});
```

## Common Patterns

### Parameterized Tool Factory

Create tools dynamically from configuration:

```typescript
function createCrudTool(entity: string, basePath: string) {
  return defineTool({
    name: `${entity}_list`,
    description: `List all ${entity} records`,
    risk: "read",
    input: z.object({
      page: z.number().int().min(1).default(1),
      limit: z.number().int().min(1).max(100).default(20),
    }),
    execute: async (input, context) => {
      const response = await fetch(
        `${basePath}?page=${input.page}&limit=${input.limit}`
      );
      return response.json();
    },
  });
}

const usersTool = createCrudTool("users", "https://api.example.com/users");
const ordersTool = createCrudTool("orders", "https://api.example.com/orders");
```

### Tool with Confirmation

Require user confirmation for destructive actions:

```typescript
const deleteTool = defineTool({
  name: "delete_record",
  description: "Permanently delete a record",
  risk: "destructive",
  input: z.object({
    id: z.string().describe("Record ID to delete"),
  }),
  execute: async (input, context) => {
    const confirmed = await context.ask(
      `Are you sure you want to delete record ${input.id}? This cannot be undone.`
    );

    if (confirmed.toLowerCase() !== "yes") {
      return { deleted: false, reason: "User cancelled" };
    }

    await fetch(`${API_URL}/records/${input.id}`, { method: "DELETE" });
    return { deleted: true, id: input.id };
  },
});
```

### Tool with Retry Logic

Handle transient failures gracefully:

```typescript
async function withRetry<T>(
  fn: () => Promise<T>,
  retries: number,
  delay: number
): Promise<T> {
  for (let i = 0; i <= retries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (i === retries) throw error;
      await new Promise((r) => setTimeout(r, delay * Math.pow(2, i)));
    }
  }
  throw new Error("Unreachable");
}
```
