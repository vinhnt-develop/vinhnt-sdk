# Cài đặt

## Các tầng cài đặt

### Tối thiểu (3 package)

Bắt đầu với các package thiết yếu cho tích hợp LLM cơ bản.

```bash
pnpm add @vinhnt-sdk/schema @vinhnt-sdk/core @vinhnt-sdk/tools
```

| Package | Mục đích |
|---------|----------|
| `schema` | Định nghĩa kiểu và xác thực |
| `core` | Runtime và điều phối cốt lõi |
| `tools` | Giao diện gọi công cụ |

### Có công cụ (7 package)

Thêm sandbox, guard, quản lý session và quyền truy cập.

```bash
pnpm add @vinhnt-sdk/schema @vinhnt-sdk/core @vinhnt-sdk/tools \
  @vinhnt-sdk/sandbox @vinhnt-sdk/guard \
  @vinhnt-sdk/session @vinhnt-sdk/permission
```

| Package | Mục đích |
|---------|----------|
| `sandbox` | Môi trường thực thi cô lập |
| `guard` | Bộ lọc đầu vào/đầu ra an toàn |
| `session` | Quản lý vòng đời phiên |
| `permission` | Kiểm soát truy cập và quyền hạn |

### Đầy đủ (18 package)

Cài đặt SDK đầy đủ với tất cả phần mở rộng.

```bash
pnpm add @vinhnt-sdk/schema @vinhnt-sdk/config @vinhnt-sdk/llm \
  @vinhnt-sdk/tools @vinhnt-sdk/sandbox @vinhnt-sdk/guard \
  @vinhnt-sdk/session @vinhnt-sdk/permission \
  @vinhnt-sdk/step-executor @vinhnt-sdk/core \
  @vinhnt-sdk/provider-openai-compatible \
  @vinhnt-sdk/plugin @vinhnt-sdk/knowledge @vinhnt-sdk/event \
  @vinhnt-sdk/mcp @vinhnt-sdk/trace @vinhnt-sdk/security @vinhnt-sdk/lsp
```

## Biến môi trường

Thiết lập API key cho nhà cung cấp bạn chọn.

```bash
# DeepSeek (khuyến nghị)
export DEEPSEEK_API_KEY="your-api-key"

# OpenAI (tùy chọn)
export OPENAI_API_KEY="your-api-key"

# Anthropic (tùy chọn)
export ANTHROPIC_API_KEY="your-api-key"
```

## Xác minh cài đặt

Sau khi cài đặt, xác minh rằng mọi thứ biên dịch chính xác.

```bash
npx tsc --noEmit
```

Nếu lệnh thoát mà không có lỗi, vinhnt-sdk đã sẵn sàng sử dụng.
