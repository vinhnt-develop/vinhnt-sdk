# Changesets

Hello and welcome! This folder has been automatically generated by
[@changesets/cli](https://github.com/changesets/changesets).

## Adding a changeset

Run `pnpm changeset` to add a changeset. It asks a few questions and writes a
markdown file into this folder. Commit that file. The next release will read it.

## Format

Each changeset is a markdown file with a leading front matter block:

```md
---
"@vinhnt-sdk/schema": patch
"@vinhnt-sdk/core": minor
---

Description of the change.
```

## Releasing

1. `pnpm changeset version` — consumes the changesets in this folder, bumps
   package versions and updates CHANGELOGs.
2. `pnpm publish-packages` — runs `pnpm build && pnpm test:run && changeset publish`
   to build, verify and publish each bumped package to npm.

The release workflow `.github/workflows/release.yml` automates this on `main`.
